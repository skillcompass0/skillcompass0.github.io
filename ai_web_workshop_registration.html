8-hour workshop plan

From idea → website → live product.

Four practical 2-hour sessions across Saturday and Sunday. Every session builds on the previous one.

01

AI & Web Basics

2 hours · Saturday
  • What is AI and Generative AI?
  • Where do we use AI in everyday life?
  • What can AI do well — and where can it make mistakes?
  • AI safety, privacy and responsible use
  • How websites work: HTML, CSS and JavaScript
  • Introduction to VS Code
  • Introduction to GitHub Copilot
  • Build a simple first webpage using Copilot
🎯 First win: your child builds their first webpage with AI.
02

Build Your Portfolio

2 hours · Saturday
  • Understand basic HTML structure
  • Create the portfolio homepage
  • Add About Me, My Skills, My Projects and Contact sections
  • Use GitHub Copilot to generate and explain code
  • Introduction to CSS
  • Add colours, fonts, spacing, cards and layouts
  • Personalise the website with interests and creativity
🎯 Build milestone: a personalised portfolio starts taking shape.
03

Make Your Website Interactive

2 hours · Sunday
  • Introduction to JavaScript through examples
  • Add 1–2 interactive features: dark mode, buttons, fun-fact generator or project filtering
  • Add simple animations
  • Use Copilot to modify and improve the website
  • Learn how to ask AI to explain code
  • Learn how to use AI for debugging
  • Test and improve the website
🎯 Build milestone: your website responds, moves and feels like a real product.
04

Publish & Showcase

2 hours · Sunday
  • Introduction to Git and GitHub
  • Create a GitHub repository
  • Upload/push the website from VS Code
  • Publish using GitHub Pages
  • Test the live website on desktop and mobile
  • Check links, images, spelling and privacy
  • Make final improvements with Copilot
  • Demo Day: each student presents their portfolio
🚀 Final milestone: leave with a live portfolio + GitHub repository.

Questions parents may have

Frequently asked questions.

Does my child need previous coding experience?

No. The workshop starts with AI and web basics and is designed for curious learners aged 10–15. Prior experience is helpful but not required.

What will my child actually build?

Each child builds a personal portfolio website with HTML, CSS and JavaScript, adds interactive features, and publishes the website using GitHub Pages.

Is this an AI-only workshop?

No. AI is used as a creative coding assistant, while children also learn the fundamentals of HTML, CSS, JavaScript, Git and GitHub.

Is the workshop online?

Yes. All four sessions are conducted live online across Saturday and Sunday.

What is included in the ₹1,499 fee?

The fee covers the complete 8-hour, 2-day workshop with four live sessions.
